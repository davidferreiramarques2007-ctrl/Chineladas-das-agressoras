Como jogar

É simples: mire, lance e tente acertar o centro!

  1. 1. Arraste o dedo ou mova o mouse para posicionar a mira.
  2. 2. Toque/clique para lançar o chinelo. No computador, também vale a barra de espaço.
  3. 3. Alvos menores valem mais pontos; acertar o centro dobra a pontuação.
  4. 4. Faça três acertos seguidos para ganhar bônus de sequência.
  5. 5. No multiplayer, todos entram pelo mesmo código ou QR Code.
